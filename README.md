# 每日一题 · 一年级上册

一个手机端优先的每日数学思考题页面，按苏教版一年级上册进度编排，含答案与家长讲解。

## 用法

直接用浏览器打开 `index.html` 即可，无需联网、无需安装。

- 每天自动显示当天的题目（按日期计算，跳过周六周日）
- 答案默认收起，点「看答案」才展开
- 底部可回看往期

## 添加题目

打开 `index.html`，在 `var QS = [` 的数组末尾追加一条：

```js
{ lv:3, tag:"间隔 · 楼梯", q:"题目……", hint:"提示……", a:"答案", why:"讲解……" },
```

- `lv`：难度 1–3，显示为星星
- 日期会自动往后顺延一个工作日

## 题单范围

当前 29 道，覆盖：间隔问题、还原问题、等量代换、周期、鸡兔同笼、图形计数、排列、逻辑推理、开放题等一年级奥数常见题型。
